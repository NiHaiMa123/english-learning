## New language

1. `have access to ...` — 有权访问……
   - `This agent has access to your email.`

2. `grant access` — 授予访问权限
   - paired with `revoke access`

3. `revoke access` — 撤销访问权限
   - `You can revoke access at any time.`

4. `sensitive action(s)` — 敏感操作
   - `Payment is a sensitive action.`

5. `should require user approval` — 应该需要用户批准
   - contrast: `require user approval` states a stronger/current requirement; `should require ...` preserves “应该”.

6. `explicit permission` / `without explicit permission` — 明确许可 / 未经明确许可
   - `Agents shouldn't modify files without explicit permission.`

## Successful learner production

- `you can revoke agent's access at any time`
- `this agent has access to your email`
- `agents shouldn't modify files without explicit permission`
- correctly selected `grant` / `revoke` as opposite access-control actions
- final integrated instruction:
  - `agent has access to the calendar, but sensetive actions should require user approval. don't modify files without explicit permission. user can revoke access at any time.`

## Important corrections

- `few bugs` -> `fewer bugs` when expressing “更少”
- `require user approval` -> `should require user approval` when the Chinese includes “应该”
- spelling: `sensetive` -> `sensitive`
- articles such as `the agent` / `the user` can improve specificity in a concrete instruction, but the learner's meaning was clear without them.

## Assessment

The vocabulary-first format worked better than the earlier multimodal lesson. The learner successfully reused several new chunks in full written sentences during the same session. Written Agent-style production remains a useful consolidation method.

## Manual Normal session — Blender clipping / collision

### Mode

- Manual `摸鱼` Normal lesson
- Vocabulary-foundation phase
- Text-only

### Topic

Blender / 3D clipping, collision, penetration, and clearance.

### Review result

Prompt: “我建议先修复穿模问题。”

Learner wrote:
- `i suggest fixing the model overboard`

Assessment:
- `suggest + -ing` was retrieved independently and correctly in a changed context.
- `model overboard` was not a valid expression for 穿模.

Preferred wording:
- `I suggest fixing the clipping issues first.`
- or `I suggest fixing the mesh intersections first.`

Status: `suggest fixing ...` moved to demonstrated written mastery.

### New language

1. `clip through ...` / `clipping` — 穿过 / 穿模
   - `The boot clips through the thigh when the knee bends.`

2. `collision` — 碰撞 / 碰撞设置
   - `Even with collision enabled, the skirt still clips through the legs.`

3. `penetration` / `reduce penetration` — 穿透 / 减少穿透
   - `Increasing the collision quality may reduce penetration.`

4. `self-collision` — 自碰撞
   - `Enable self-collision ...`

5. `intersect with ...` / `intersect with itself` — 与……穿插 / 与自身穿插
   - preferred over the learner-created `self-penetration` in this context.

6. `prevent A from doing B` — 防止 A 做 B
   - `Collision can prevent the cloth from intersecting with the body.`

7. `clearance` / `add a small clearance between A and B` — 间隙 / 在 A 和 B 之间留一点间隙
   - `Adding a small clearance between the skirt and the leg can reduce penetration.`

8. `increase collision quality` — 提高碰撞质量

### Learner production

- `the skrit clips through the thigh when model is walking`
  - spelling: `skrit` -> `skirt`
  - `the character is walking` is more natural than `model is walking` here.

- `even with collision enabled, the skirt still clips through legs`
  - target structure correct; add `the` before `legs` in the concrete context.

- `improving collision quality may reduce penetration`
  - correct and natural; `increasing collision quality` is more parameter-oriented.

- `enable self-collision can prevent skirt from self-penetration`
  - needed correction to either `Enable ... to prevent ...` or `Enabling ... can prevent ...`.
  - preferred `intersecting with itself` over `self-penetration`.

- `collision can prevent the cloth from intersecting the body`
  - `prevent A from doing B` correctly produced.
  - `intersecting with the body` is slightly more natural.

- `adding a small clearance between the skirt and the leg can reduce penetration`
  - correct.

- correctly distinguished `collision`, `clearance`, and `clipping` in a contrast exercise.

### Final written reuse

Prompt:
“膝盖弯曲时，靴子会穿进大腿。先在靴子和腿之间增加一点间隙。如果仍然穿模，再提高碰撞质量。”

Learner wrote:
- `the boots clip through the legs, when the knees bend. add a small clearance between the boots and the legs first. if penetrations still occur, increase the collision quality`

Assessment:
- successfully reused `clip through`, `add a small clearance between ...`, and `increase collision quality`.
- pluralizing the whole situation is acceptable, but the comma before `when` is unnecessary.
- `penetration` is better treated as a mass noun here: `if penetration still occurs` or simply `if clipping still occurs`.

Suggested polished version:
- `The boots clip through the legs when the knees bend. Add a small clearance between the boots and the legs first. If clipping still occurs, increase the collision quality.`
