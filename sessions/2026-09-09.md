## New language

1. `have access to ...` — 有权访问……
   - `This agent has access to your email.`

2. `grant access` — 授予访问权限
   - paired with `revoke access`

3. `revoke access` — 撤销访问权限
   - `You can revoke access at any time.`

4. `sensitive action(s)` — 敏感操作
   - `Payment is a sensitive action.`

5. `should require user approval` — 应该需要用户批准
   - contrast: `require user approval` states a stronger/current requirement; `should require ...` preserves “应该”.

6. `explicit permission` / `without explicit permission` — 明确许可 / 未经明确许可
   - `Agents shouldn't modify files without explicit permission.`

## Successful learner production

- `you can revoke agent's access at any time`
- `this agent has access to your email`
- `agents shouldn't modify files without explicit permission`
- correctly selected `grant` / `revoke` as opposite access-control actions
- final integrated instruction:
  - `agent has access to the calendar, but sensetive actions should require user approval. don't modify files without explicit permission. user can revoke access at any time.`

## Important corrections

- `few bugs` -> `fewer bugs` when expressing “更少”
- `require user approval` -> `should require user approval` when the Chinese includes “应该”
- spelling: `sensetive` -> `sensitive`
- articles such as `the agent` / `the user` can improve specificity in a concrete instruction, but the learner's meaning was clear without them.

## Assessment

The vocabulary-first format worked better than the earlier multimodal lesson. The learner successfully reused several new chunks in full written sentences during the same session. Written Agent-style production remains a useful consolidation method.
