## Review results

### `count toward ...` vs `count as ...`
Learner produced:
- `this approval counts toward three of the required approvals, but can't be counted as administrator's approval`
- `this result can count toward the last record, but it can't count as people's judges`

Assessment:
- The structural distinction was mostly understood: `count toward` for contributing to an overall requirement, `count as` for classification.
- Lexical choices were inaccurate (`three of the required approvals`, `last record`, `people's judges`).
- Keep on short-interval review.

Preferred forms:
- `This approval counts toward the three required approvals, but it doesn't count as an administrator's approval.`
- `This result can count toward the final score, but it can't count as a manual review.`

### `reassess whether ...` + `meet the acceptance criteria`
Learner independently produced:
- `if input changes, reassess whether the final review meets the acceptance criteria`

Assessment:
- Target sentence pattern retrieved correctly.
- `the result` was more accurate than `the final review` for the prompt.
- `still` was omitted, but the core pattern was usable.

Preferred:
- `If the input changes, reassess whether the result still meets the acceptance criteria.`

### `workaround` / `use a workaround`
Learner produced:
- `if can't find the root cause temptly, use a workaround, but don't assume solving the root cause`

Assessment:
- Correctly retrieved `use a workaround` and `root cause`.
- `temporarily / for now` needed for the adverb.
- `don't assume` still needs a full clause: `don't assume it addresses the root cause`.
